# OVA · Teoría de Colas

Objeto Virtual de Aprendizaje sobre teoría de colas, hecho con HTML, CSS y JavaScript.

- **Estudiante:** Joel Sebastián Ortiz Marcado
- **Asignatura:** Teoría General de Sistemas · Ingeniería de Sistemas · 2026-2
- **Institución:** Universidad Simón Bolívar · Campus Cúcuta

## Contenido
Introducción, conceptos clave, modelo M/M/1 con calculadora, video, juego “Cajero express”, quiz de 12 preguntas y referencias.

## Estructura
```
index.html      Página principal
style.css       Estilos
script.js       Lógica (calculadora, juego y quiz)
assets/logo.png Logo de la universidad
```

## Cómo usarlo
Abre `index.html` en cualquier navegador. No necesita instalación.

## Cómo publicarlo en GitHub
```
git init
git add .
git commit -m "OVA teoría de colas"
git branch -M main
git remote add origin https://github.com/TU-USUARIO/ova-teoria-de-colas.git
git push -u origin main
```
Para tener un link público: Settings → Pages → Branch `main` → Save.
